
# ☁️ CloudVault

CloudVault is a cloud engineering portfolio project built in a self-hosted Ubuntu lab using VirtualBox, Docker, Nginx, and Python Flask.

The goal of this project is to demonstrate core cloud engineering skills including Linux administration, containerization, networking, web application deployment, and infrastructure management.

---

## 🚀 Features

- Ubuntu Server hosted in Oracle VirtualBox
- Docker container deployment
- Python Flask web application
- Nginx web server
- Local cloud lab environment
- GitHub version control
- Web-based application access

## 📦 Installation

Clone the repository:

```bash
git clone https://github.com/YOUR_USERNAME/CloudVault.git
cd CloudVault
```

Install Flask:

```bash
pip3 install flask
```

Run the application:

```bash
python3 app.py
```

Open in your browser:

```text
http://localhost:5000
```

or

```text
http://YOUR_VM_IP:5000
```
